# Glossary

- `api-gateway`: public HTTP edge and BFF
- `user-service`: session, auth, profile, and ban ownership
- `matchmaking-service`: search queue and match creation
- `chat-service`: chat rooms, WebSocket transport, signaling
- `moderation-service`: message checks and reports
- `notification-service`: async notification fanout
- `Redis`: fast coordination, queues, and shared ephemeral state
- `PostgreSQL`: durable application storage
- `NATS JetStream`: async event path
