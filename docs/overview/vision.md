# Vision

NektoKZ is an anonymous chat and matchmaking platform.

The product goal is to let a user enter quickly, find a match, and continue in
real-time text or voice chat without a heavy signup flow.

Primary goals:

- anonymous-first onboarding
- fast matchmaking and room creation
- real-time chat and signaling
- production-friendly container deployment

Non-goals:

- social network features
- long-lived public profiles as the core product
- monolithic server-side rendering of all flows
